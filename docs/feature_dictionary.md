# Feature dictionary

Source: GMSC `cs-training.csv` (US consumer credit, 2011). Only features the data supports are built; revenue growth, cash-flow stability, transaction regularity, savings behaviour, business history and working-capital indicators are NOT available in this dataset and are therefore NOT implemented.

| Feature | Group | Type | Inputs | Formula | Financial significance | Edge cases | Leakage check |
|---|---|---|---|---|---|---|---|
| `RevolvingUtilizationOfUnsecuredLines` | numerical | numeric | raw column | balance on revolving unsecured credit / total credit limits | How much of available revolving credit is used; high use signals financial stress. | Raw values reach 50,708; clipped in the training-only pipeline. | Uses only applicant attributes known at application time; not derived from the target. |
| `age` | numerical | count | raw column | age in years | Life-stage proxy for stability and earnings. | Rows with age < 18 removed. | Uses only applicant attributes known at application time; not derived from the target. Age-based models raise fairness concerns; see docs. |
| `MonthlyIncome` | numerical | numeric | raw column | monthly gross income | Repayment capacity. | ~19.8% missing (imputed in-pipeline, with `income_reported` flag); 0 treated as unreported in derived features. | Uses only applicant attributes known at application time; not derived from the target. |
| `NumberOfOpenCreditLinesAndLoans` | numerical | count | raw column | count of open loans and credit lines | Breadth of existing credit relationships. | None. | Uses only applicant attributes known at application time; not derived from the target. |
| `NumberRealEstateLoansOrLines` | numerical | count | raw column | count of mortgage / real-estate loans and HELOCs | Secured-debt exposure. | None. | Uses only applicant attributes known at application time; not derived from the target. |
| `NumberOfDependents` | numerical | count | raw column | dependents excluding the borrower | Household obligations. | ~2.6% missing (imputed in-pipeline). | Uses only applicant attributes known at application time; not derived from the target. |
| `NumberOfTime30-59DaysPastDueNotWorse` | numerical | count | raw column | times 30–59 days past due in last 2 years | Early-stage repayment problems. | Sentinel 96/98 set to NaN. | Observation window overlaps the period before the target window; exact overlap unverifiable. |
| `NumberOfTime60-89DaysPastDueNotWorse` | numerical | count | raw column | times 60–89 days past due in last 2 years | Moderate repayment problems. | Sentinel 96/98 set to NaN. | Same window caveat as the 30–59 column. |
| `NumberOfTimes90DaysLate` | numerical | count | raw column | times 90+ days past due | Serious repayment problems; the target itself is 90+ days past due. | Sentinel 96/98 set to NaN. | HIGH-RISK for leakage: the dictionary gives no time window for this count and it is conceptually close to the target. Cannot be verified without timestamps; documented as a limitation. |
| `income_reported` | derived | binary | MonthlyIncome | 1 if MonthlyIncome is present and > 0, else 0 | Missing income correlates with how DebtRatio behaves and with default rate; the model should know it. | NaN or 0 income -> 0. | Uses only applicant attributes known at application time; not derived from the target. |
| `debt_ratio_valid` | derived | numeric | DebtRatio, MonthlyIncome | DebtRatio if income_reported == 1 else NaN | Debt-to-income burden (monthly obligations / monthly income) restricted to rows where it is a real ratio. | When income is unreported, DebtRatio is NaN (it behaves like an absolute amount there). Information loss from this choice should be checked by ablation in Phase 2. | Uses only applicant attributes known at application time; not derived from the target. |
| `est_monthly_obligations` | derived | numeric | DebtRatio, MonthlyIncome | DebtRatio * MonthlyIncome if income_reported == 1 else NaN | Approximate absolute monthly debt/living obligations (per dictionary definition of DebtRatio). | NaN when income unreported. Currency not stated in the source. | Uses only applicant attributes known at application time; not derived from the target. |
| `income_per_household_member` | derived | numeric | MonthlyIncome, NumberOfDependents | MonthlyIncome / (NumberOfDependents + 1) if income_reported == 1 else NaN | Income available per person supported (borrower + dependents). | Denominator >= 1, never zero. NaN if income unreported or dependents missing. | Uses only applicant attributes known at application time; not derived from the target. |
| `total_past_due_events` | derived | count | three past-due count columns | 30–59 + 60–89 + 90+ counts | Overall delinquency history. | NaN if any component is NaN (sentinel rows). | Inherits the 90+ column's window caveat. |
| `has_90plus_delinquency` | derived | binary | NumberOfTimes90DaysLate | 1 if 90+ count > 0 else 0 | Any serious delinquency on record. | NaN where the count is NaN. | Inherits the 90+ column's window caveat. |
| `utilization_over_limit` | derived | binary | RevolvingUtilizationOfUnsecuredLines | 1 if utilization > 1 else 0 | Balance above credit limit. | None. | Uses only applicant attributes known at application time; not derived from the target. |

Raw `DebtRatio` is not passed to the model directly; it enters as `debt_ratio_valid` (see edge cases). There are no true categorical variables in this dataset; binary flags are derived.
